# Elementor 템플릿 가져오기 안내

5개 섹션 템플릿(JSON)에는 **PC/태블릿/모바일 기기별 설정이 이미 포함**되어 있습니다:
배경 이미지 3종(2560/1600/1080세로), 타이포 기기별 크기(예: 제목 50/38/30px),
여백·폭 기기별 값, 모바일 경량 360영상 자동 선택, reduced-motion 대응.

## 순서 (중요 - 반드시 이 순서로)

### 1. 미디어 먼저 업로드
`wp-assets/` 의 파일들을 **이번 달(2026년 7월) 안에** 미디어 라이브러리에 업로드하세요.
템플릿이 `.../uploads/2026/07/파일명` 경로를 참조하므로, 7월에 올리면 자동으로 연결됩니다.
- 필수: bg-wave 3종, device-front-cutout-1100w, device-quarter-1200w,
  beam-off/on-1536w, product-360-960.mp4, product-360-640.mp4, product-360-poster,
  logo-finewave-1575w
- 파일명을 바꾸지 마세요. (WP가 같은 이름 파일에 -1을 붙이면 그 URL로 위젯에서 재선택 필요)
- 8월 이후에 작업하게 되면: 가져오기 후 이미지가 비어 보이는 위젯만 클릭해서
  미디어 라이브러리에서 재선택하면 됩니다 (1~2분 작업).

### 2. 보조 CSS 추가 (1회)
`fw-templates-support.css` 내용을 Elementor 사이트 설정 > 사용자 정의 CSS
(없으면 외모 > 사용자 정의하기 > 추가 CSS)에 붙여넣기.

### 3. 템플릿 가져오기
1. WP 관리자 > 템플릿(Templates) > 저장된 템플릿 > 상단 "템플릿 가져오기" 버튼
   > JSON 5개 선택 업로드
   (또는 Elementor 편집기에서 회색 폴더 아이콘 > 내 템플릿 탭에서도 접근 가능)
2. Finewave 페이지를 Elementor로 편집 > 원하는 위치에서 폴더 아이콘 > 내 템플릿 >
   "FW 01 히어로"부터 순서대로 **삽입**
3. 기존 섹션과 교체: 새 템플릿 섹션이 정상 표시되는지 확인 후, 대응하는 기존 섹션을
   우클릭 > 삭제 (기존 섹션을 먼저 지우지 말 것 - 비교하면서 교체)

### 4. 확인
- 하단 반응형 모드 아이콘 > 태블릿/모바일 전환하며 배경·글자 크기 확인
- 프리뷰에서: 히어로 순차 등장, 빔 깜빡임, 360 회전(스크롤 진입 시 1회) 동작 확인
- 모바일 실기기에서 360 영상이 640본(146KB)으로 로드되는지 (F12 > Network)
